# Bensky Website

## 📌 Description

Bensky est un site web qui présente différents contenus, notamment le sport,
la musique, le cinéma, la diversité et le leadership.

## 🛠️ Technologies utilisées

- HTML
- CSS
- JavaScript
- C#
- SQL

## 📂 Structure du projet

- `Bensky website/` : partie principale du site
- `backend/` : partie serveur
- `sport/` : contenu lié au sport
- `cinema/` : contenu lié au cinéma
- `musique/` : contenu musical

## 🚀 Installation

1. Télécharger ou cloner le projet.
2. Ouvrir le dossier dans Visual Studio Code.
3. Lancer le projet avec le serveur approprié.
